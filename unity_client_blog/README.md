| 美术资源 | **一律不开源** | 贴图 / 模型 / prefab / 材质 / 动画 / 音频 / 字体 / 截图等资源不进仓库，文章里仅作现象说明 |
| 依赖 | 只引用不纳入 | 第三方库 / 引擎 / 上游依赖以引用或 submodule 方式给出，不复制其源码 |
| 许可证 | MIT | 与服务端模块一致 |
| 代码仅为片段 | **掠过** | 若文章里的代码只是说明性片段、不构成可独立复现的模块，则该篇不单独开源，跳过即可 |
| 强制性 | **非强制** | 开源属加分项而非硬要求；受许可 / 工程约束或素材版权限制时，可只发文章不开代码 |

**落地判定顺序**：① 代码能否独立复现？否 → 掠过；② 是否含美术资源？是 → 剥离后再判；
③ 依赖能否以引用/submodule 给出？能 → 开源最小可运行集 + MIT；不能 → 只发文章。
三步任一不满足即可停在上一步，不视为违规。
