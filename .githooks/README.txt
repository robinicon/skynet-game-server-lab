仓库纪律配置（git discipline）
================================

本目录随仓库分发，集中存放提交纪律的自动化配置。

规则一：md 文档一律不入库
--------------------------------
- .gitignore 顶层用 *.md（含大小写变体）忽略所有 Markdown 文件；
  文档、规范、问题台账、博客正文一律只在本地保留。
- .githooks/pre-commit 在提交前二次拦截：即使 git add -f 强制暂存了
  某个 md，提交也会被拒绝，并列出被拦截的文件路径。
- 本地文件不受影响，随时可读可改，只是不进入版本库。

启用方式（每个 clone 执行一次）
--------------------------------
    git config core.hooksPath .githooks

若不启用，忽略规则（.gitignore）仍然生效，只是失去钩子这层拦截。

其他纪律（见 .gitignore 对应段落）
--------------------------------
- 美术资源（art_plan/out 等）不入库，只留规范与台账。
- 未发布工程（ch9 及以后、unity_client、csdn_cover）暂不入库。
- 日志、编译产物、Python 产物、skynet 依赖均不入库。
